現在のブランチからGitHub PRを作成してください。

## 補足情報

$ARGUMENTS

## 手順

### 1. 状態の把握

以下を並列で実行:

- `git status` — 未コミットの変更がないか確認
- `git branch --show-current` — 現在のブランチ名
- `git log --oneline main..HEAD` — ベースブランチからの全コミット
- `git diff main...HEAD --stat` — 変更ファイルの統計
- `git remote -v` — リモートの確認

### 2. 事前チェック

- **未コミットの変更がある場合**: ユーザーにコミットするか確認する
- **main ブランチにいる場合**: 新しいブランチを作成するか確認する
- **リモートに push されていない場合**: `git push -u origin <branch>` で push する

### 3. 変更内容の分析

- `git diff main...HEAD` で全差分を確認
- 全コミットメッセージから変更の全体像を把握（最新だけでなく全コミット）
- 変更の種類を判断（新機能 / バグ修正 / リファクタ / ドキュメント 等）

### 4. PR の作成

`gh pr create` で PR を作成する:

#### タイトル

- 70文字以内
- 変更の本質を簡潔に表現

#### 本文

以下のフォーマットで HEREDOC を使って作成:

```
gh pr create --title "PRタイトル" --body "$(cat <<'EOF'
## Summary
- 変更点1
- 変更点2
- 変更点3

## Test plan
- [ ] テスト項目1
- [ ] テスト項目2

Generated with Claude Code
EOF
)"
```

#### オプション

- ベースブランチが指定されていれば `--base` で指定
- ドラフトが適切な場合は `--draft` を付ける

### 5. 結果報告

```
🚀 PR作成完了
━━━━━━━━━━━━━━━━━━
URL: （PR の URL）
タイトル: （PRタイトル）
ベース: （ベースブランチ） ← （ヘッドブランチ）
変更: （ファイル数、追加/削除行数）
━━━━━━━━━━━━━━━━━━
```
