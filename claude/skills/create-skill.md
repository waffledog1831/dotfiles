# スキルクリエイター

ユーザーの要望に基づいて、Claude Code用のカスタムスキル（`.md`ファイル）を作成します。

## 要望

$ARGUMENTS

## 指示

以下の手順でスキルを作成してください。

### 1. 要件の整理

ユーザーの要望から以下を読み取ってください（不明な点は最もありそうな前提で補完）:

- **スキル名**: スラッシュコマンドとして使う名前（英語、ケバブケース）
- **目的**: このスキルが何をするか
- **引数**: `$ARGUMENTS` で受け取る入力の形式
- **振る舞い**: Claudeにどう動いてほしいか

### 2. スキルファイルの生成

以下のフォーマットで `.md` ファイルを作成してください:

```markdown
# スキルタイトル

[スキルの概要説明]

## 入力

$ARGUMENTS

## 指示

[具体的な指示内容]

## 引数の例

- `例1` → 説明
- `例2` → 説明
```

### 3. ファイルの保存

- 保存先: `C:/project/dotfiles/claude/skills/{スキル名}.md`
- ファイル作成後、内容をユーザーに見せて確認を取る

### 4. 注意点

- プロンプトは具体的かつ明確に書く（曖昧な指示はClaude の出力品質を下げる）
- `$ARGUMENTS` を適切に配置して、ユーザー入力を受け取れるようにする
- 日本語で記述する（技術用語は英語OK）
