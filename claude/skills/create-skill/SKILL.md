ユーザーの要望に基づいて、Claude Code用のカスタムスキルを作成します。

## 要望

$ARGUMENTS

## 指示

以下の手順でスキルを作成してください。

### 1. 要件の整理

ユーザーの要望から以下を読み取ってください（不明な点は最もありそうな前提で補完）:

- **スキル名**: スラッシュコマンドとして使う名前（英語、ケバブケース）
- **目的**: このスキルが何をするか
- **引数**: `$ARGUMENTS` で受け取る入力の形式
- **振る舞い**: Claudeにどう動いてほしいか

### 2. スキルディレクトリとSKILL.mdの生成

以下のフォーマットでスキルを作成してください:

- 保存先: `C:/project/dotfiles/claude/skills/{スキル名}/SKILL.md`

```markdown
---
name: スキル名
description: スキルの説明（Claudeが自動判定に使う）
argument-hint: "[引数の形式]"
---

[スキルの指示内容]

## 引数の例

- `例1` → 説明
- `例2` → 説明
```

### 3. 確認

- ファイル作成後、内容をユーザーに見せて確認を取る

### 4. 注意点

- YAMLフロントマターの `description` は必ず書く（Claudeの自動判定に使われる）
- 手動実行のみのスキルには `disable-model-invocation: true` を付ける
- プロンプトは具体的かつ明確に書く（曖昧な指示はClaudeの出力品質を下げる）
- `$ARGUMENTS` を適切に配置して、ユーザー入力を受け取れるようにする
- 日本語で記述する（技術用語は英語OK）
