# 会話

# 作業
- 依頼された作業は自律的に完了まで進める。結果に影響する不明点だけ確認する。
- ユーザーの未コミット変更を勝手に破棄・退避しない。既存の作業ブランチやワークツリーを尊重する。
- 新規作業はデフォルトブランチを基に作業ブランチを作る。継続作業では現在のブランチを使う。
- データ削除、本番への反映、課金、アクセス権の変更は、依頼の範囲に含まれるか確認し、未承認なら実行前に承認を求める。
- 変更に応じた検証を行い、変更点・検証結果・未確認事項を報告する。

# スキル・エージェント
- 普段の相談・実装は自分で行う。固有の運用手順が必要ならスキルを使う。
- キャラクターの指名、独立した文脈での調査、別視点のレビュー、切り分け可能な大きな作業に限りエージェントを使う。固定の順番で委任しない。

# 機密情報
- `.env`、`.env.*`、`secrets/`、認証情報は明示的な指示がない限り読み取らず、ログ・回答・コミットに含めない。
