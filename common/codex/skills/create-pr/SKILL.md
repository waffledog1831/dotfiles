# PR 作成・更新

- status、現在のブランチ、リモート、デフォルトブランチ、既存 PR を確認する。
- デフォルトブランチ上なら作業ブランチを作る。無関係な変更は含めない。
- PR 作成・更新の仕上げとして `../simplify/SKILL.md` を読み、ベースとの差分に含まれる依頼対象のコードとドキュメントへ適用する。
- シンプル化後の差分全体とコミットを確認し、変更内容に応じた検証を行う。
- シンプル化による変更も含めて未コミットの依頼対象をコミットし、通常の push でブランチを公開する。force push は明示的な依頼がない限り行わない。
- 同じブランチに既存 PR があれば更新し、重複作成しない。未完了なら draft にする。
- タイトルと本文は日本語。本文には具体的な変更後の挙動、検証結果、必要な注意点を書く。リポジトリの PR テンプレートがあれば従う。
- 複数行の本文はファイルに書いて `gh pr create --body-file <file>` に渡すか、API の構造化引数を使う。
- 作成・更新した PR の URL を報告する。マージは別途依頼された場合だけ行う。
