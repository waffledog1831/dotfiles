# 新規作業ブランチ

- 現在のブランチ、未コミット変更、リモート、デフォルトブランチを確認する。デフォルトブランチはリモート情報から取得し、取得できなければ推測で切り替えない。
- 継続作業なら現在の作業ブランチを使う。
- 新規作業ではリモートを fetch し、取得したデフォルトブランチの先端から `<種別>/<内容>` のブランチを作る。ローカルの main を checkout / pull する必要はない。
- 指定された名前を優先し、未指定なら作業内容から命名する。名前の確認だけで作業を止めない。
- 未コミット変更が新規作業に無関係なら切り替えず、別ワークツリーを使うか状況を確認する。勝手に stash・reset しない。
- fetch に失敗した場合は最新性を保証できないことを伝え、ブランチ作成が依頼の範囲であればローカルで確認できるベースを使う。
- 作成したブランチ名とベースを報告する。
