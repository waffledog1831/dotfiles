# Codex 運用ガイド

## 配置

| 管理元 | 配置先 | 内容 |
|--------|--------|------|
| `common/codex/AGENTS.md` | `~/.codex/AGENTS.md` | アイの口調、日本語、作業の境界 |
| `common/codex/config.toml` | `~/.codex/config.toml` | 承認・アクセス権・通知・役割の登録 |
| `common/codex/agents/` | `~/.codex/agents/` | キャラクターと役割別の設定 |
| `common/codex/skills/` | `~/.agents/skills/` 配下の同名リンク | 必要時に読み込む運用手順 |

`CODEX_HOME` を指定すると設定とエージェントの配置先が変わります。ユーザースキルの探索先は `~/.agents/skills/` です。
スキルは個別にリンクし、別のスキルや認証情報・履歴を含むディレクトリ全体は置き換えません。

Codex CLI を別途インストール・ログインしたうえで、リポジトリのルートから実行します。

```bash
bash common/install.sh
```

Git と Claude Code の設定も適用します。既存の設定ファイルはリンクに置き換わるため、必要ならバックアップしてください。
実ディレクトリとの衝突は内容を削除せずエラーにします。設定変更後は Codex を再起動します。

## 運用

モデルと推論レベルは Codex の既定値を使用し、タスクに応じて選択します。
プロジェクト固有の構成や検証方法は各リポジトリの `AGENTS.md` に記述します。

普段はアイが直接作業します。スキルは [一覧](skills.md)、役割は [キャラクター一覧](arcana.md) を参照してください。
レビュー役には変更しないよう指示し、リリアには担当範囲の実装を任せます。Codex の役割設定でサンドボックスを独立に変更できるとは扱わず、各役割はセッションの権限を継承します。レビュー役の編集禁止は自然言語の指示であり、権限による強制ではありません。

## アクセス権

`default_permissions = "development"` で、通常はルートの読み取り、ワークスペースと一時ディレクトリの書き込みを許可します。
ワークスペースの `.env`、`.env.*`、`secrets/` へのアクセスは deny で拒否します。追加権限は `on-request` で要求します。

設定の読み込みとスキルの探索は Codex CLI `0.159.0-alpha.3` で確認しています。名前付き権限プロファイルに対応する Codex が必要です。古いバージョンで認識されない場合は更新してください。
Linux などでの再帰 glob 展開は `glob_scan_max_depth = 8` に制限しています。深い階層や実行中に新しく作られた対象への適用は、プラットフォームとバージョンに依存するため完全な秘密情報の隔離とは扱わないでください。
サンドボックスを回避する起動オプションや承認した権限拡張でも保護範囲が変わります。

設定の定義は [公式スキーマ](https://github.com/openai/codex/blob/main/codex-rs/core/config.schema.json) を参照してください。
