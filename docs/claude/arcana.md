# 冒険者ギルド「Arcana」 — エージェント一覧

> 冒険者ギルド「Arcana」をテーマにしたマルチエージェントシステムです。
> ギルドマスター（ユーザー）は受付嬢リリアとだけ会話し、リリアが冒険者を編成してクエストを遂行します。

## システム構成

```
ギルドマスター（ユーザー）
  ↕ 会話（唯一の窓口）
受付嬢リリア（lilia）— クエスト受付・編成・報告
  ↓ タスクを振る         ↑ 成果を報告
┌─────────────────────────────────────────┐
│  剣士ガルド（gald）    — 実装          │
│  斥候シオン（sion）    — 調査          │
│  魔法使いメルル（merle）— リファクタ   │
│  僧侶セラ（sera）      — テスト/修正  │
│  賢者オルドス（ordos）  — レビュー     │
└─────────────────────────────────────────┘
```

> **重要**: リリアは自分で実作業をしません。すべてのタスクを適切な冒険者に振り、成果をまとめてギルドマスターに報告します。

## 使い方

### 基本の流れ

ギルドマスター（ユーザー）はリリアにだけクエストを依頼します。リリアが適切な冒険者を編成し、成果をまとめて報告します。

```
@lilia この機能を実装してほしい
@lilia このバグを調査して修正して
@lilia このコードをレビューしてほしい
```

> **注意**: 冒険者を直接呼び出すことも技術的には可能ですが、基本はリリア経由で依頼してください。リリアが最適な編成を判断します。

### エージェントチーム

リリアが複数の冒険者を並列で編成して協力させます（`CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` 有効化済み）。

## Arcana 書庫

各プロジェクトに `arcana/` ディレクトリを作成し、冒険者たちの活動記録とナレッジを蓄積します。

```
プロジェクト/
└── arcana/
    ├── quests/        # クエスト掲示板 — クエストの管理
    ├── chronicles/    # 年代記 — クエストの詳細記録
    └── grimoire/      # 魔導書 — ナレッジベース
```

> `arcana/` はグローバル `.gitignore` で除外されるため、Git には含まれません。

### 初期化

```bash
bash /path/to/dotfiles/arcana-init.sh
```

### 各ディレクトリの役割

| ディレクトリ | 名前 | 用途 |
|-------------|------|------|
| `quests/` | クエスト掲示板 | 進行中・完了済みクエストの管理。リリアが管理 |
| `chronicles/` | 年代記 | クエストの詳細な作業記録（ログ） |
| `grimoire/` | 魔導書 | 得られた知識・ベストプラクティス |

### 各冒険者の記録方針

| 冒険者 | 記録内容 |
|--------|---------|
| リリア | クエスト管理（quests）、全体の記録指示 |
| ガルド | 実装の戦果報告（chronicles）、実装ノウハウ（grimoire） |
| シオン | 構造の特徴、隠れた依存関係（grimoire） |
| メルル | リファクタリングパターン、最適化の知見（grimoire） |
| セラ | バグの原因パターン、テスト戦略（grimoire） |
| オルドス | 設計判断の理由、アーキテクチャの教訓（grimoire） |

全エージェントは `memory: project` が有効で、永続メモリとしても知見を蓄積します。

## 冒険者の追加

`claude/agents/{キャラクター名}.md` を作成してください。
フォーマットは既存の冒険者ファイルを参考にしてください。
