# コミット

- status、未ステージ・ステージ済みの diff、最近のコミットを確認する。
- 今回の作業に関係するファイルだけをステージする。ユーザーの無関係な変更や機密情報を含めない。既存のステージ済み変更を混ぜる必要がある場合は確認する。
- メッセージは日本語の `<prefix>: <変更内容>`。prefix は feat / fix / docs / refactor / test / chore / ci など、変更の意図に合わせる。本文は理由や注意点が必要な場合だけ書く。
- 帰属表記は実行ツールの設定に従い、別ツールの名前を手動で追加しない。
- コミット後に status を確認し、ハッシュと変更の要点を報告する。フック失敗は原因を直して再実行し、フックを迂回しない。
- 変更がなければコミットしない。push はこのスキルでは行わない。
